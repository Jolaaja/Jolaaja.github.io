# Andi Adi Saputra — Digital Portfolio

Personal developer profile and selected project portfolio built for GitHub Pages.

## Pages

- `index.html` — personal profile and professional links
- `portfolio.html` — selected projects and case summaries

## Stack

HTML5, CSS3, JavaScript, GitHub Pages.

## Features

- Responsive profile and dedicated project page
- Persistent light and dark themes
- Subtle motion with reduced-motion accessibility support
- Background-free profile portrait

Upload `index.html`, `portfolio.html`, `styles.css`, `premium.css`, `script.js`, and `README.md` to the repository root. Upload `profile.png` to `assets/` and keep the existing CV PDF in that folder.
